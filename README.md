# Device tree for Nothing Phone 2 (Pong)
##### Axion branch - Required for build

## Setup

Clone the correct branch into **device/nothing/Pong**

You can do so by selecting the branch corresponding to your rom at the top and executing this command:
> git clone https://github.com/Sevo9128/device_nothing_Pong.git -b axion device/nothing/Pong


## Other

Get everything needed to build a custom rom for Pong at [my collection](https://github.com/Sevo9128/nothing-Pong-dev-collection)
